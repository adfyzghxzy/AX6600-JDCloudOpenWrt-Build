# R1 — Standard nền
OpenWrt 25.12.6 cho JDCloud AX6600 RE-CS-02, eMMC.

- Chỉ có Standard, không tăng tốc luồng NSS/ECM.
- LuCI cơ bản; overlay F2FS lưu cấu hình qua khởi động lại.
- Mặc định LAN `192.168.10.1`; WiFi `JDCloud`, mật khẩu `14789632`.
- Bản nền đã thử khởi động, LAN/WiFi, WAN DHCP, lưu cấu hình và cài gói APK.
- Chưa có các bổ sung Argon/tiếng Việt, Athena LED và bộ QMI/MBIM tích hợp của R5.

Qua LuCI dùng `sysupgrade.bin`; bỏ **Keep settings** để nhận toàn bộ mặc định mới. File `factory.bin` chưa được xác nhận flash bằng U-Boot mod. Kiểm tra `SHA256SUMS`.

Bản mới hơn: [R5 — Standard và NSS](https://github.com/adfyzghxzy/AX6600-JDCloudOpenWrt-Build/releases/tag/v25.12.6-jdcloud-r5).
